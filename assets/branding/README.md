Created for [Thura Aung](https://thuraaung2493.github.io/) using the built-in image generation tool.

- [logo.png](logo.png): transparent project mark for documentation and project identity.
- [social-preview.jpg](social-preview.jpg): opaque 2:1 banner for GitHub social sharing and the project README.

The shared palette follows Thura Aung’s portfolio: blue `#28518D`, navy `#25313D`, pale blue `#A8C7F5`, and soft gray `#EDF0F3`.

## GitHub social preview

Upload `social-preview.jpg` through **Repository settings → General → Social preview → Edit → Upload an image**. Keep this setting in sync when replacing the banner; a README image does not automatically configure GitHub’s social preview.

[GitHub’s image requirements](https://docs.github.com/en/repositories/managing-your-repositorys-settings-and-features/customizing-your-repository/customizing-your-repositorys-social-media-preview): PNG, JPG, or GIF under 1 MB; at least 640 × 320 pixels, with 1280 × 640 recommended. This banner preserves the generated 2:1 layout and is exported as JPEG to stay below the upload limit.
